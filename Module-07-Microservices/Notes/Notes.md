## What is Microservices?

Microservices is an architectural style in which an application is divided into small, independent services. Each service performs a specific business function and communicates with other services using APIs.

## Features of Microservices
- Independent deployment
- Easy maintenance
- High scalability
- Better fault isolation
- Faster development
